Cainiao Horarios

Base publica para la aplicacion web de horarios. Esta version no contiene datos reales, nombres de agentes, IDs internos ni copias del Google Sheet corporativo.

Estado del proyecto

La interfaz esta lista para GitHub Pages. La conexion de horarios debe hacerse despues mediante una capa segura que entregue solo la informacion permitida.

Sin datos sensibles

Frontend estatico

HTML, CSS y JavaScript simple para publicar en GitHub Pages sin dependencias.

Privacidad primero

El repositorio publico queda separado del Google Sheet y de cualquier dato de agentes.

Siguiente paso

Definir API, Apps Script web app o backend privado para consultar horarios filtrados.
